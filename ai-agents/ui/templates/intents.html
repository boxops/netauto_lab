Standing intents declare persistent network expectations. suppress — skip investigation for known-flapping links. escalate — force human approval regardless of risk level. monitor — proactively poll a Prometheus query or Nautobot API path and open an incident when the threshold is breached (use nautobot:// prefix for Nautobot API paths). chaos_schedule — run a chaos scenario on a cron schedule (requires CHAOS_TOOLS_ENABLED=true).
